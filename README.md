# Marketing the Arts (AMGT 671) class website

A one-page site for the graduate course Marketing the Arts at American University.
Everything lives in `index.html` (HTML, CSS and the tote-bag logo are all inline), plus `favicon.svg`.

- To preview: open `index.html` in a browser.
- To edit copy: open `index.html` in any text editor and change the words between the tags.
- To publish free on GitHub Pages: see "Putting it online" in [HOW-WE-BUILT-THIS.md](HOW-WE-BUILT-THIS.md).
