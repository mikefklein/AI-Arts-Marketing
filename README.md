# Marketing the Arts (AMGT 671) class website

The website for the graduate course Marketing the Arts at American University.

Live site: https://mikefklein.github.io/AI-Arts-Marketing/

## What's here

| File | What it is |
| --- | --- |
| `index.html` | Home: the lamppost, the welcome, and the map of the block |
| `lineup.html` | The schedule, guests, and how a class night goes |
| `studio.html` | What students learn and make |
| `mixtape.html` | What We're Listening To (the class playlist) |
| `backstage.html` | The instructor, house rules, and how the site was made |
| `box-office.html` | Questions and answers, and contact links |
| `404.html` | The "wrong alley" page for broken links |
| `styles.css` | The look of every page |
| `llms.txt` | A plain-text summary of the site for AI agents and assistants |
| `favicon.svg` | The small tote bag icon |
| `build-your-own-website.pdf` / `.pptx` | A seven-slide guide to making your own site, downloadable from the Backstage page |
| `HOW-WE-BUILT-THIS.md` | How this was built with an AI model, and how to do it yourself |

## Editing

Open any `.html` file and change the words between the tags. The header and footer are repeated in each page, so a change to the menu has to be made in every file.
